# v21：订单页面与查找入口整理

基准：正式版 v20，main `c6731f58b574ac256fe7c231f79c80441940d1cf`。
恢复点：`backup/before-order-ui-20261022`，与以上正式版一致。
恢复口令：恢复到“订单界面整理前 v20”。通过新提交恢复网站文件，不删除云端订单或 Git 历史。

## 本次变更

- 底部“今日订单”更名为“订单”；继续显示所选订单的真实日期、状态和版本。午夜不自动切换、清空订单。
- 删除订单页重复的查询面板；查询完整保留在“更多 → 查订单”。“检查新订单”和“打开最新订单”合并为“查看最新订单”，复用现有检查并打开逻辑，按提交时间查最新，包含切换前及读取期间的未保存输入保护。
- 查看最新订单旁增加 44px 可点击范围的说明图标。仅展开说明，点外部或 Escape 关闭。
- 订单搜索“取消”改为“返回订单”；保留已输入数量和原分类位置。“收起”仍仅关闭键盘。盘货搜索仍叫“取消”。
- 保存状态持久显示在保存按钮上方：保存中、服务器确认成功及时间、失败/无法确认、版本冲突。保存中禁用保存按钮；后续输入仍显示未保存改动。修改记录读取失败不撤销已经确认的保存成功。
- 网络错误可能发生在写入后读取确认阶段，因此显示“未能确认云端保存成功”，不误报成功，也不武断声称未写入。原事务、版本校验和重试逻辑不变。
- 待审核订单禁用供应商文字复制/分享，说明老板娘定稿后可复制。定稿后按钮明确为“复制本类订货文字”“分享本类订货文字”；草稿和样例原有预览导出保留。
- 空分类显示“本分类暂无订货商品”。固定入口复制成功仅显示“已复制”。

## 保持不变

129 种商品与原始分类数量 45/66/18、ID、名称、顺序、单位及两项可选单位；自定义数字键盘；库存空白含义；老板娘定稿权限；已提交库存只读；备份恢复、原历史档案、照片与 LOGO。未修改 Firebase 规则、数据库或任何 Google Sheets。
