# v25：统一当前订单，恢复库存文字显示

问题：v24 的 sharedCount() 对大伟要求本机盘货编号与当前云端订单编号一致。通过历史查询、链接或另一设备打开订单时，订单页显示云端订单，而盘货页可能回落到旧本机草稿，导致订货数量不一致。

订单列表恢复原有库存文字，不再插入库存编辑框。已提交订单搜索中的库存只读，库存修改入口在盘货页；保留订货数量编辑和原有数字键盘。

验证：93项自动测试通过，增加编号不匹配、有独立草稿、无本机草稿、跨页面修改/保存/再读取、草稿保留和订单库存显示回归。esbuild构建与diff检查通过。不修改数据库规则、129项商品目录、真实订单或Google Sheets。
