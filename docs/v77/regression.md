# v77 盘货、订单与历史档案回归

本次从 v76 正式版出发，调整四处网页行为并校订 README。运行结果和发布状态在完整回归结束后登记。

| 用餐门店的操作场景 | 回归标准 |
| --- | --- |
| 向下滚动盘货或订单 | 吸顶栏按红色标题的实际高度就位。覆盖三个手机宽度、常规和 59px 模拟顶部安全区，以及草稿和定稿。 |
| 切换盘货、订单和更多 | 第一次进入从顶部开始，同一页面记住返回位置。搜索退出恢复原列表位置。切换订单或账号时不沿用旧记录，输入未完成时保留原页面。 |
| 断网查询或保存 | 单份、列表、日期、分页和修改历史查询提示无法读取。创建、保存、定稿分别检查写入提示。 |
| 打开旧历史档案 | 单份请求失败仍显示其他日期，提示部分失败；重开可重试。目录失败时保留本次会话已读取内容。空目录有明确提示。 |
| 核对商品与规则 | 新建目录 147 种，保留稳定编号、双语名称及独立的库存和订货单位。原始目录、名称映射、单位修正、规则和开场文件继续校验已核准的指纹。 |

云端测试使用隔离的 Firestore 模拟器。浏览器套件使用 Chromium 与 WebKit，未使用门店真实订单。实体手机的系统状态栏仍需以真机表现为准。
