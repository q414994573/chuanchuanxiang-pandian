## 本轮修改

- 新盘货的13种库存单位：土豆개；鸡精、人造肉、水晶豆皮、粉条、腐竹、玉米面、粉耗子、莲藕粉耗子、牛筋面、火锅粉包；芝麻酱통；藤椒油瓶。
- 仅改变新盘货库存默认单位；目录、订货单位、数值、129项分类顺序、原始历史快照均保持。已保存草稿/历史库存不静默换单位或换算数量。莲藕粉耗子的订货仍由原模板选박스或봉，库存为包。
- 两账号修改已提交的待审核订单后，停顿1.5秒自动保存，手动立即保存保留。保存期间继续输入的内容保留并排队再次保存；数量与单位、库存修订使用原事务和审计。
- 未上传修改按模式、账号、订单分别留在本机。重开时只在同一版本安全恢复；云端已更新/定稿、另一标签页改写、本机存储失败时暂停自动覆盖，并保留备份与查看云端新版入口。
- 断网/临时失败重试，重复请求复用修改ID；完成数字才上传，包括1.0、01、1.250。未完成数字也进入本机记录和手动备份，不将半截输入写入云端。
- 字段排序不同不再误判冲突；异步读取期间的新输入、换账号后的旧响应不能覆盖当前状态。退出、切订单、定稿、新建盘货时保护正在保存的内容。
- 开始下一次盘货会移除网址旧order参数；原草稿先保留恢复副本。
- `npm run build:preview` 可重建正式/预览共用bundle，入口资源标记v26。
