# v45 · 订单操作区紧凑排版

日期：2026-10-26。基于正式 v44，按用户订单页截图调整上下按钮区，让屏幕显示更多商品。

## 页面变化

- 本分类的三个操作改为同一行等宽按钮：**复制本类、分享本类、查看文字**。完整的无障碍名称仍分别为“复制本类订货文字”“分享本类订货文字”“查看本类订货文字”。
- 缩小这三个按钮的文字、边距和圆角，保留至少 44px 的点击高度。上方原有定稿/离线/草稿说明保留，减少其默认段落留白。
- 已定稿的底部操作区改为横向排列：左边是较小的“解除定稿”，右边是原说明“已定稿，可按分类复制发送。”。说明允许自然换行；按钮仍有 44px 点击高度。
- 样式限定在分类文字操作区与已定稿页脚。草稿保存、定稿操作区和文字预览面板保留原布局。
- 这些布局对两个共同盘货账号相同。商品、单位、数量、分类、云端、定稿/解除定稿和复制分享逻辑均无变更。
