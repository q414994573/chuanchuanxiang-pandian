## 这个网站是做什么的

首尔川川香麻辣烫用的手机盘货和订货页。店里的人用 iPhone 14 Pro Max。老板娘可能用三星手机，从 KakaoTalk 里打开链接。

它要做的事：按店里走路的顺序看 129 种商品，分开记库存和订货，确认后把订货文字复制出去。2026-10-20 起，正式首页可以登录后把复核过的盘货提交成云端订单，两个人改同一份。网页仍然不会替你把消息发进 KakaoTalk，链接要自己分享。没登录或没联网时，本机盘货照旧保存在这部手机里。

## 必须守住的规则

- 商品正好 129 种：韩国食品 45、中国食品 66、其他商品 18。名称、编号、单位、分类、原来的走动顺序都不能随便改。不能重，不能少。
- 库存数量和订货数量是两回事。库存单位和订货单位也可以不同。
- 空着不是 0。写成 0 才表示填了 0。库存是 0 也不能自动生成一笔订货。不知道的数字不要猜。
- 감자수제비（土豆面片）：1 大包 = 2 小包，按大包记，不要自动翻倍或减半。
- 고수（香菜）：提醒再看一次冰箱。网页代替不了开冰箱。
