# v51：盘货搜索显示全部分类的匹配商品

用户截图中的原样输入是 `大葱腐竹粉丝`。v50 的盘货页仍按所选韩国分类过滤，导致只显示大葱；订货搜索页能显示三种。搜索匹配本身成功，问题在盘货结果和格子导航再次限制了分类。

此前测试把这种分类限制写成了预期结果，因此之前“没有问题”的结论不成立。v51 已改正预期，并用这条原样搜索词作为回归用例。

## 修复后的行为

- 盘货页搜索显示全部分类命中的商品，并注明“搜到 3 种商品 · 全部分类”。
- 从韩国、中国、其他、饮料任一分类发起该搜索，都显示大葱、腐竹、粉丝。
- 上一格、下一格、暂后盘可以沿完整搜索结果跨分类操作，填写值保留。
- 搜索时隐藏分类按钮和“下一个没盘的”，清空或取消搜索后恢复原分类盘货。
- 正常未搜索的盘货仍按分类显示；定稿的只读权限保持有效。
