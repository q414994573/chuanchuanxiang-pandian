# v48 · 直接替换数量、商品名称播报与库存单位修正

日期：2026-10-26（韩国时间）。基于正式 v47，远端基线为 `83ec8d785b23bdef5465dea56e20bbf9bb85b591`。正式入口与预览入口缓存版本均为 `20261026-v48`。

## 使用方式

### 改数字时直接输入

打开已填数字的自定义键盘后，整串数字在原格内高亮。例如打开 `12`，按 `8` 得到 `8`；按 `1`、`8` 得到 `18`。只打开再收起，保留原值。重新点同一活动格不会再次选中、重置撤销基准或把已经输入的数字覆盖掉。

选中效果只放在原来的数值格内，键盘不增加说明行。删除、加减、上一格、下一格、撤销及库存零值继续按现有规则工作。原生文字输入与自定义数字键盘的切换会结束选中状态。小数最多三位，数量上限沿用原规则。

### 商品名称播报

在“更多 → 操作反馈”开启“商品名称播报”，可用“试一下”试听。默认关闭；开关仅保存在当前设备，与声音和震动开关分别保存，两个账号使用相同规则。

开启后，点商品名称或可编辑的库存、订货数量格，播报该商品原有的主名称。中文主名称用普通话语言设置，韩文主名称用韩语设置，优先选择设备现有的对应本地语音。名称本身和括号翻译没有改动。

- 快速点另一件商品，结束上一段播报，只播当前商品，旧点击不排队。
- 播报待启动和播放期间暂停按键提示音；播报结束或失败后恢复按键音。数字输入始终即时处理，震动开关独立。
- 输入数字、自动保存、云端同步、页面重绘不会重复播报商品名。
- 后台、离开页面、退出账号或关闭播报时停止发声。语音接口失败、没有及时启动或没有返回结束事件时，释放按键音占用。
- 定稿后仍可点名称听播报，数量锁定继续有效。

### 两个库存单位

| 商品 | ID | 库存单位 |
|---|---|---|
| 韩国食品的娃娃菜 | `kr:31` | `개` |
| 中国食品的水饺 | `cn:21` | `包` |

旧版本只改了新建盘货的默认值，旧草稿仍可能带着原单位。本版补上旧草稿处理：空白且未盘过的库存格采用正确单位；有旧库存数值的格子在明确重新输入数字后采用正确单位，即使重新输入的数值仍是 `12` 也有效。只打开、关闭、删数字或查看旧记录不会把旧数值直接改标为另一种单位。重新输入后，数值和单位一起保存，也一起撤销。

历史已定稿订单保留当时的库存数值与单位。没有推测箱、包、个的换算关系；订货栏单位及订货数量没有随库存单位改变。

## 回归时发现并修复的问题

1. 本机备份写入失败后，内存数值已改变但编辑器仍保留旧输入状态，后续数字可能接到错误位置。现保留实际输入并消费首次替换状态，恢复保存后继续输入和撤销均一致。
2. 已保存订单输入 `0.001` 时，中间的 `0.0` 曾被提前当成无效数量。现保留编辑中的小数片段，输入完整后才更新订单数值；未完成的输入继续阻止离开。
3. 盘货写入零订货后，直接切换分类、商品、页面或清空/退出搜索，可能留下隐藏的无效订货项。现完整的零在离开时归为不订并持久保存；未写完的小数保持原格并提示。库存 `0` 继续表示实际库存为零。
4. 草稿订单及订单搜索输入 `0.0` 后离开也采用不订规则，继续输入成 `0.01` 仍有效。
5. 库存编辑撤销可能跳回订单页，或只撤销数值而漏掉单位。现保持适合库存编辑的页面，并将数值与单位作为一次操作恢复。
6. 云端仅修改了当前格的单位时，旧编辑器可能把远端变更当成本机可撤销内容。现将数值、单位与对应状态一起检查。
7. 接收另一份新草稿或定稿快照后，清理上一份记录的活动编辑器与撤销基准，避免旧记录内容被恢复到新记录。
