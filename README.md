## 网站现在有什么

- **129种商品**：韩国食品45种、中国食品66种、其他商品18种。名称、编号、单位、分类和原来的走动顺序都保留。
- 每项显示商品名称、库存、订货数量、订货单位。库存和订货是两栏，单位可以不同。
- 没有最低备货量，也没有重点商品或星标。129种都是普通商品。
- 默认展示全部129种。可以搜索、按分类筛选、只看本次订货、只看已填库存、只看未填库存。
- 点搜索框进入手机全屏搜索：本机搜索历史、清空历史、固定快捷入口、中文和韩文都能搜，并看到库存和订货。搜索历史只留在当前浏览器。
- 「仅看已填库存」：数字0、小数和非空文字都算已填写。库存空着不算。其他商品原来没有库存栏，也不算已填库存。
- **订货明细**：只列出真实填写且数量大于0的项目。页上的分类笔数按当前数据计算，不写死某一类是0。支持复制。复制只表示文字已复制，不表示已经发给别人。
- **特殊提醒**：감자수제비 1大包=2小包，按大包填，不要自动翻倍或减半；고수（香菜）要再看一次冰箱。
- 页面保留门头照片和招牌。
- 韩国食品、中国食品、其他商品是三种货，不一定是三家供货商。供货商怎么对应，还要单独配置。

## 每周更新方式

首页 `index.html` 里有一份备用快照，并会读取仓库根目录的 `current-order.json`。核对并确认一周订单后，更新该 JSON 即可，不必每周重写首页。读取失败时，页面继续显示内嵌的带日期快照，不编造新数字。

更新时必须逐项核对：

- 总数129，分类45/66/18。不要加回星标或最低备货量。
- 商品编号、名称、库存、订货数量、单位，以及各类实际订货笔数。
- 不得把空白改成0，不得猜测订货数量或单位。
- 土豆面片按大包，香菜有复看提醒。
- 页面上要看得出盘点日期和是否已确认。
