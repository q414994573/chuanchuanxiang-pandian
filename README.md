## 每周更新方式

网站首页 `index.html` 含有已确认的备用快照，并且会从仓库根目录的 `current-order.json` 读取最新**已确认**的当周快照。今后核对并确认每周订单后，更新该 JSON 文件即可，不必每周重写首页。加载失败时，页面显示内置的带日期历史快照，不伪造最新数据。

更新时必须逐项验证：
- 总数129，分类45/66/18，★标记47；
- 商品ID、名称、库存、订货数量、单位及各类别订货明细；
- 不得将空白改为0，不得猜测订货数量或单位；
- 特殊商品包装单位和香菜复盘提示；
- 显示数据的**盘点日期、确认状态**。
